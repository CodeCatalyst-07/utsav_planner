# India Locale Configuration Pack (`src/domain/config/in`)

Domain data pack specifically tuned for Indian celebrations (weddings, birthdays, community festivals):

- Budget allocation splits across decor, catering, venue, photography, attire, and rituals
- Per-plate catering cost bands across Tier 1, 2, and 3 cities
- Milestone lead times (e.g., muhurat booking, pandit consultation, lehenga/sherwani tailoring)
- Regional vendor category defaults (mehendi artists, dhol players, caterers, decorators)

### Invariants:

- Static JSON / TypeScript configuration data only. Zero side-effects.
